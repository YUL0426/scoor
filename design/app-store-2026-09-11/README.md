# Scoor App Store 스크린샷 — World 중심 개편

2026-09-11. **iPhone 한국어 5장: 개인 기록 2장 + World 3장.** 이전 9월 10일 파일은 그대로 보관했습니다.

## 제출 순서

`upload/ko-KR/iphone-6.9/`의 PNG를 파일명 순서대로 등록하세요.

| 순서 | 제목 | 실제 앱 화면 |
|---|---|---|
| 01 | 오늘 하루, 몇 점인가요? | 하루 점수 입력 |
| 02 | 세상의 토픽을 함께 발견해요 | World의 토픽과 공개 반응 피드 |
| 03 | 같은 토픽, 다양한 시선. | 토픽 상세, 글로벌 점수, 최근 반응 |
| 04 | 멀리 있어도, 이어지는 공감. | 서로 다른 관점의 반응 목록과 참여 버튼 |
| 05 | 나의 하루도, 차곡차곡. | 개인 점수와 한 줄 기록 |

통계·회고·달력 전용 이미지는 제외했습니다. 02~04번을 연속 배치해 토픽을 찾고, 서로의 관점을 읽고, 자신의 생각으로 참여하는 경험을 강조했습니다.

5장 모두 **1320 × 2868, 8비트 RGB PNG, sRGB, 알파·투명도 없음**입니다. 전체 보기 `preview-iphone-6.9.png`는 검토용이므로 업로드하지 않습니다. `Scoor-AppStore-World-ko-KR.zip`에 업로드 파일과 안내서를 담았습니다.

## iPad 상태

현재 `Scoor.xcodeproj/project.pbxproj`의 앱 Debug·Release에 `TARGETED_DEVICE_FAMILY = "1,2"`가 설정돼 있어 iPhone과 iPad가 지원 대상입니다. 9월 10일 iPad 시뮬레이터에서 기존 기록 화면의 실행과 캡처는 확인했습니다. 이는 iPad 전용 레이아웃과 전체 사용성 검증 완료를 의미하지 않습니다.

이번 수정본은 iPhone용입니다. 지원 기기 설정은 변경하지 않았고 iPad를 추가 실행하지 않았습니다. iPad 유지 여부가 확정되면 같은 구성으로 별도 크기 세트를 준비할 수 있습니다.

## 화면의 출처와 예시 데이터

- iPhone 17 Pro Max / iOS 26.5에서 현재 앱의 화면을 캡처했습니다. 화면 내부의 UI·문구·점수를 편집 이미지로 재구성하지 않았습니다.
- World는 실제 `RemoteWorldService`와 출시 화면 경로를 사용하되, DEBUG 전용 로컬 URLSession fixture로 예시 토픽·닉네임·반응을 제공합니다. 모든 요청을 로컬에서 처리하며 쓰기 요청은 거부합니다. 운영 데이터와 계정에는 게시하지 않았습니다.
- 참여 수와 전체 점수는 예시 반응에서 계산했습니다. 국가별 비교 등 출시 경로에 없는 옛 미리보기 UI는 사용하지 않았습니다.
- 02~04번 하단에 **예시 토픽과 반응으로 구성한 화면입니다.**를 표시했습니다. 실제 활동량이나 사용자 사례를 나타내지 않습니다.
- 01·02·03·05는 XCTest의 PNG 캡처입니다. 04는 같은 캡처 실행의 화면 기록에서 마지막 반응까지 보이는 **1320 × 2868 원본 프레임**을 추출했습니다. 확대·UI 교체 없이 배치했습니다. 원본 기록은 H.264 영상이므로 해당 한 장은 손실 압축을 거친 소스입니다.

## 검증과 변경 사항

- 단일 컴파일 작업으로 Debug 캡처 빌드 성공. 캡처 중 이미지 출력이나 다른 시뮬레이터 실행을 겹치지 않았습니다. 사용한 시뮬레이터는 종료했습니다.
- 5장 전체의 시각 검토와 파일 규격 검사를 마쳤습니다. 파일별 크기·색상·투명도·SHA-256은 `validation.json`에 있습니다.
- 자동 캡처는 한국어 선택자 문제를 수정한 뒤 토픽 상세까지 진행됐습니다. 마지막 반응은 화면에 보이지만 `isHittable`이 false라 검사가 실패했습니다. 기록 영상으로 실제 표시를 확인하고 프레임을 사용했습니다. 전체 UI 테스트 통과로 기록하지 않습니다.
- 향후 재캡처용 검사는 터치 가능 여부 대신 화면 내 좌표를 검사하도록 수정했습니다. 최종 검사 수정 후 재빌드·재실행은 하지 않았습니다.
- World 상세에서 실제 반응이 있어도 `0+`로 표시되던 숫자를 표시 중인 실제 반응 수로 수정했고, 캡처에서 예시 반응 7개와 숫자 7의 일치를 확인했습니다.
- App Store Connect 업로드·심사 제출은 하지 않았습니다.

## 재출력

기존 브랜드 레드·검정·웜 화이트와 큰 두 줄 제목을 유지했습니다. 텍스트와 배치는 `source/render.swift`에서 수정할 수 있습니다. 저장소 루트에서 아래를 실행하면 이미지를 한 장씩 출력합니다.

```sh
swift -module-cache-path /tmp/scoor-artwork-module-cache design/app-store-2026-09-11/source/render.swift iphone-6.9
python3 design/app-store-2026-09-11/source/validate_package.py
```

시각적 참고는 9월 10일 직접 확인한 [Threads](https://apps.apple.com/kr/app/threads/id6446901002), [Instagram](https://apps.apple.com/kr/app/instagram/id389801252), [X](https://apps.apple.com/kr/app/x/id333903271)의 App Store 스크린샷 구성입니다. 경쟁 앱의 로고·UI·사진·카피는 결과물에 사용하지 않았습니다. 출력 규격은 [Apple 스크린샷 규격](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)을 기준으로 했습니다.
