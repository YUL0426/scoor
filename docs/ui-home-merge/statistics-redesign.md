# 통계 탭 재설계

큰 숫자 카드와 달력이 반복되는 구성을 제거했다. 최근 7/30/90일을 선택하면 평균, 이전 동일 기간 대비 점수 차이, 일별 점수 그래프를 함께 보여준다. 그 아래에 기록한 날의 비율과 현재 연속 기록, 기간 중 최고 점수의 하루를 배치했다. 날짜별 수정용 달력은 접힌 상태로 제공한다. 통계 요약은 시스템 공유 메뉴로 전달할 수 있다.

집계는 기록된 날짜만 사용한다. 미기록일은 0점으로 취급하지 않고 실제 0점 기록은 평균과 그래프에 포함한다. 비교 기간에 기록이 없으면 변화량을 표시하지 않는다. 미래 날짜는 제외한다.

관심 선택 화면은 제목을 없앴다. 왼쪽 편집으로 전체 카테고리를 열어 변경하고 오른쪽 완료로 저장한다. 편집 중 취소는 기존 선택을 유지한다.

검증: 기간 경계·미기록일·0점 계산 단위 테스트 2개와 관심 편집/저장 및 7·30·90일 전환 UI 테스트 1개 통과. iPhone 17 Pro 화면은 statistics-screenshots에 보관했다.
