# 홈과 개인 기록의 역할 정리

- 홈: 서로의 하루를 읽는 피드. 브랜드 질문 → 내 하루 기록 → 정렬·감정 필터 → 점수와 한 줄 이야기. 기존 댓글, 반응, 신고, 새로고침, 페이지네이션 유지.
- 월드: 주제에 대한 점수와 대화.
- 기록: 어느 화면에서든 오늘 점수 입력. 하단의 다른 항목과 동일한 행에 배치.
- 마이페이지: 프로필, 오늘·주간·감정 흐름 카드, 개인 인사이트, 최근 기록 수정, 통계, 달력, 토픽 평가 이력, 방명록.
- 슬로건: `How's your day? scoor!` 홈, 스플래시, 온보딩, 첫 기록과 점수 입력에 반영.
- 텍스트 입력 중 커스텀 숫자패드는 숨긴다. 키보드 완료 또는 화면의 입력 완료로 숫자패드를 복원하며 기존 점수·텍스트를 보존한다.

피드와 홈의 중복을 없애기 위해 하단은 Home / World / + 기록 / My Page 네 항목으로 구성했다. 새로운 소셜 데이터나 가짜 실시간 수치는 추가하지 않았다.

검증: iOS Simulator 빌드 통과. iPhone 17 Pro UI 테스트에서 홈의 기록 진입, 피드 탭 제거, 텍스트 입력 시 숫자패드 숨김·복원, 75점 저장 후 마이페이지 표시를 확인했다. 테스트 화면 캡처를 final-screenshots에 보관했다. 전체 회귀 테스트 및 실기기 검증은 이번 실행 범위에 포함하지 않았다.
