# 내비게이션 및 화면 구성 2차 변경

- 홈 로고는 44pt 높이로 화면 중앙 정렬. 슬로건 기록 진입은 별도 행으로 분리.
- 홈의 실시간 / 인기 / 비슷한 기분 아래 감정 카테고리 제거.
- 월드: 지금 뜨거운 토픽 → 아이콘과 텍스트를 키운 카테고리 메뉴 → 사용자 의견 영역. 전체 토픽의 중복 세로 목록 제거. 카테고리를 선택하면 해당 토픽으로 진입할 수 있다.
- 하단: 홈 / 월드 / 기록 / 알림(하트) / 마이페이지.
- 알림: 모두 / 팔로우 / 대화 / 언급 / 리포스트 필터. 현재 수신 알림 API가 없어 빈 상태로 제공하며 실제 활동 이벤트 수신은 후속 서버 작업이 필요하다.
- 마이페이지: 기록(점수, AI 인사이트, 최근 기록, 내 토픽 기록), 통계(요약, 달력, 연속 기록), 방명록. 스크롤 중 섹션 탭 고정.

빌드 및 iPhone 17 Pro 시뮬레이터의 화면 전환 테스트로 검증. 실제 소셜 알림 수신은 이번 UI 검증 범위에 포함되지 않는다.

## 3차 정리

홈의 슬로건·입력 행 제거. 오른쪽 관심 탭에서 한 가지 카테고리를 선택하고 저장하여 피드를 필터링한다. 월드의 카테고리 버튼은 한 줄 아이콘·텍스트 형태로 축소하고 토픽 없음/의견 없음 상태를 서로 배타적으로 표시한다. 점수 입력의 왼쪽 버튼은 뒤로가기이며 입력 화면을 닫는다. 마이페이지의 프로필 로고를 제거하고 이름을 강조했으며, 오늘 점수는 100pt 요약·수정 카드로 축소했다. 기록/통계/방명록은 아이콘과 강조색으로 구분한다.
