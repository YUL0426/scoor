# Scoor 일본어 · 프랑스어 · 브라질 포르투갈어 현지화

2026-09-16. 앱 UI 카탈로그 654개 키에 `ja`, `fr`, `pt-BR` 번역을 적용했다. 가입 화면, 예시 기록, 기록 입력, 피드/월드, 프로필, 통계, 설정, 앱에서 정의한 오류, 접근성 문구, 알림, 사진 저장 권한 안내를 포함한다. 사용자 게시물·닉네임·서버 콘텐츠와 개발용 시드 데이터는 자동 번역하지 않는다.

**검수 상태: AI 번역 및 표현 검토 완료. 사람의 원어민 검수와 법률 전문가 검수는 수행하지 않았다.** 검수자 연결이 없으며, 사용자의 요청에 따라 AI 검토로 진행했다. 원어민 또는 법률 전문가가 승인한 번역으로 표시하면 안 된다.

## 표현 기준

- 일본어: UI는 간결한 정중체, 예시 기록은 자연스러운 일상체. `今日の一日は何点？`로 행동을 유도한다.
- 프랑스어: 프랑스 기준 어휘·문장부호, UI는 `vous`로 통일한다. 개인 예시 기록은 1인칭 구어체다. `Quelle note pour votre journée ?`를 사용한다.
- 브라질 포르투갈어: `você`, `celular` 계열의 브라질 표현, 점수는 `nota`, 설정은 `Ajustes`. 예시 기록에는 `tá`, `tô`, `galera`, `kkk`처럼 자연스러운 구어를 제한적으로 사용한다. 안내·약관에는 구어 축약을 사용하지 않는다.
- 국기와 도시가 있는 기록은 가상의 개인 예시이며, 국가 전체의 감정이나 문화적 특성을 나타내지 않는다.
- 프랑스어·포르투갈어의 날짜/요일/숫자 형식과 단복수를 지원한다. 긴 태그는 가로 스크롤로 읽을 수 있다.

## 약관과 운영 반영

`legal-policy-translations.json`에 약관 10개, 개인정보 안내 10개 단락을 각 언어로 추가했다. 원본의 `2026-09-16.1` 버전과 SHA-256을 유지하고, 번역 파일은 원본 해시와 버전이 일치해야 사용한다. 내용이나 동의 범위를 변경하는 새 정책 버전이 아니라 기존 정책의 번역이다. 추후 실질적인 내용 변경 시에는 원본·번역·서버 버전을 함께 갱신해야 한다.

운영 마이그레이션 `20260916000002_account_entry_localizations` 적용 및 읽기 검증 완료. 새 언어의 가입 기록을 허용하며, 기존 동의 이력·원본 버전·해시·인증 권한은 유지한다. 민감정보 동의는 여전히 기능 사용 시 별도로 받는다. 앱스토어 바이너리 배포는 이 작업에 포함되지 않는다.

## 확인 자료

- [전체 문구 검수표](review.csv): 키, 원문, 세 언어 번역, 검수 상태, 향후 사람 검수자/의견 입력란. 단복수 변형도 포함한다.
- [문서/카탈로그 manifest](manifest.json): 범위와 원본/번역 파일 해시.
- `terms-{ja,fr,pt-BR}.md`, `privacy-{ja,fr,pt-BR}.md`: 읽기 쉬운 약관 번역본.
- 가입 화면: [일본어](screenshots/ja-entry.png) · [프랑스어](screenshots/fr-entry.png) · [브라질 포르투갈어](screenshots/pt-BR-entry.png).
- `screenshots/`: 실제 시뮬레이터 화면. 개발용 예시 게시물의 원문은 그대로 표시된다.

검증 명령:

```sh
python3 scripts/verify_localization.py
```

카탈로그 누락, 빈 문구, 한국어 폴백, 형식 인자, 법률 문서 단락 수와 원본 해시를 검사한다. Xcode의 `Objects-normal/arm64` 경로를 인자로 주면 컴파일러가 추출한 새 키의 카탈로그 누락도 검사한다.

XCTest는 세 언어의 가입/문서/메인/기록/프로필/설정, 브라질 포르투갈어 최대 접근성 글자 크기의 버튼 접근성, 번역 문서와 시스템 권한 번들을 검증한다. 기존 인증·동의 흐름도 회귀 검증한다. 로컬 DB 테스트는 세 언어의 가입, 멱등 재시도, 철회, 잘못된 언어 거부와 기존 가입 흐름을 검증한다.

## 지원 정보의 지역 구분

앱 언어를 거주 국가로 추정하지 않는다. 한국 전화번호는 번역에서 한국의 번호임을 명시하고 국가별 지원 검색 링크를 제공한다. 번호 안내는 [보건복지상담센터](https://www.129.go.kr/109), [보건복지부 정신건강 안내](https://www.mohw.go.kr/menu.es?mid=a10706040100)를 확인했고, 국가별 검색은 [Find A Helpline](https://findahelpline.com/)으로 연결한다.
