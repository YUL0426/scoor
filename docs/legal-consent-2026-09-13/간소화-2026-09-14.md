# 가입·게시 동의 간소화

- 가입: 짧은 필수 항목, 약관/개인정보 링크, 펼쳐 보는 개인정보 수집 안내.
- 콘텐츠 이용허락과 커뮤니티 규칙은 기존 이용약관에 포함. 문서 내용·버전·해시는 유지.
- 홈 공유, 댓글, World 점수, 토픽 제안의 게시 전 별도 동의창 제거.
- 서버의 게시 권한은 필수 약관 동의로 판단. 동의 전·필수 동의 철회 후에는 전송/게시 차단 유지.
- 이전 게시 동의 철회 기록이 있으면 약관에 새로 동의할 때까지 권한을 복원하지 않음.
- 웹 한국어·영어 약관은 앱의 legal-policy.json을 직접 참조.

## 검증

- 임시 로컬 PostgreSQL에 전체 마이그레이션 적용 및 supabase/tests/legal_consent.sql 통과.
- 약관 페이지와 의존 컴포넌트 TypeScript 검사 통과.
- 변경한 Swift 파일 구문 검사 통과.
- iPhone 17 Pro 시뮬레이터 테스트 빌드 성공. LegalConsentTests 8개, 가입 동의 UI 테스트 1개 모두 통과.
- 저장소 전체 TypeScript 검사는 기존 .next/types의 중복 생성 파일 때문에 실패. ESLint는 설정 파일이 없어 실행 불가.

## 반영 순서

새 마이그레이션 20260914000001_terms_cover_publication.sql을 서버에 적용한 뒤 앱을 배포해야 합니다. 이번 작업은 로컬 코드와 임시 DB 검증이며 운영 서버 및 웹사이트에는 배포하지 않았습니다. 이전 검증결과.md의 별도 게시 동의 설명은 이번 변경으로 대체됩니다.
